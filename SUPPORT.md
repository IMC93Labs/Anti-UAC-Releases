## English

This repository is the official public support point for Anti-UAC.

### Bug reports

Use **Issues → Report a bug / Reportar un problema** for reproducible errors or unexpected behaviour.

Please include the Anti-UAC version, Windows version, the type of target application/shortcut involved and clear reproduction steps. Screenshots are useful when they do not reveal private information.

### Feature requests

Use **Issues → Request an improvement / Solicitar una mejora** for concrete improvements or new functionality.

### Questions

Use **Discussions** for general questions, usage help or conversation when Discussions is enabled for the repository.

### Security issues

Do not post sensitive security details publicly. Follow **[SECURITY.md](SECURITY.md)**.

### Before posting

- Search existing Issues first.
- Do not include passwords, tokens, private keys or personal information.
- Do not upload confidential executables or files you do not have permission to share.
- Do not use this repository to request help bypassing organizational security policy or running untrusted software with elevated privileges.

Anti-UAC is a personal hobby project maintained in free time. Support is best-effort and no response-time guarantee or SLA is provided.

## Español

Este repositorio es el punto oficial de soporte público de Anti-UAC.

### Informar de errores

Utiliza **Issues → Report a bug / Reportar un problema** para errores reproducibles o comportamientos inesperados.

Incluye la versión de Anti-UAC, versión de Windows, el tipo de aplicación/acceso implicado y pasos claros para reproducirlo. Las capturas son útiles siempre que no muestren información privada.

### Solicitar mejoras

Utiliza **Issues → Request an improvement / Solicitar una mejora** para mejoras concretas o nuevas funciones.

### Preguntas

Utiliza **Discussions** para preguntas generales, ayuda de uso o conversación cuando Discussions esté habilitado en el repositorio.

### Problemas de seguridad

No publiques detalles sensibles de seguridad en abierto. Sigue **[SECURITY.md](SECURITY.md)**.

### Antes de publicar

- Busca primero en los Issues existentes.
- No incluyas contraseñas, tokens, claves privadas ni información personal.
- No subas ejecutables confidenciales ni archivos que no tengas permiso para compartir.
- No utilices este repositorio para pedir ayuda destinada a eludir políticas de seguridad de una organización o ejecutar software no fiable con privilegios elevados.

Anti-UAC es un proyecto personal creado como hobby y mantenido en el tiempo libre. El soporte se presta en la medida de lo posible y no existe garantía de plazo de respuesta ni SLA.
