## English

### About Anti-UAC

Anti-UAC is a small Windows utility intended to make it easier to launch **applications you already trust** without dealing with repeated UAC prompts every time you open them.

The goal is convenience without globally disabling Windows User Account Control. Anti-UAC should only be used with programs whose origin and behaviour you trust.

### Main features

- Creates convenient launch shortcuts for selected applications.
- Keeps Windows UAC enabled globally.
- Designed for portable, straightforward use.
- Lets the user choose where shortcuts are saved.
- Intended for trusted local applications only.

## Español

### Acerca de Anti-UAC

Anti-UAC es una pequeña utilidad para Windows pensada para facilitar el inicio de **aplicaciones en las que ya confías** sin tener que aceptar repetidamente el aviso de UAC cada vez que las abres.

El objetivo es mejorar la comodidad sin desactivar globalmente el Control de cuentas de usuario de Windows. Anti-UAC debe utilizarse únicamente con programas cuyo origen y comportamiento sean de confianza.

### Funciones principales

- Crea accesos de inicio cómodos para las aplicaciones seleccionadas.
- Mantiene UAC activado globalmente en Windows.
- Diseñado para un uso portable y sencillo.
- Permite elegir dónde guardar los accesos directos.
- Pensado únicamente para aplicaciones locales de confianza.
