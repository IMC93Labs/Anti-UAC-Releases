# Contributing / Contribuir

[English](#english) · [Español](#espanol)

---

<a id="english"></a>
## English

This repository is primarily for **official Anti-UAC releases, public documentation and user support**. The application source code is not published here.

The most useful ways to contribute are:

- report reproducible bugs through Issues;
- suggest focused improvements through Issues;
- help other users in Discussions;
- point out mistakes or unclear wording in the public documentation.

Documentation pull requests may be reviewed, but there is no guarantee that external pull requests will be accepted or merged.

Please keep reports respectful, concise and free of credentials, private system data or executables/files you do not have permission to share.

For security-sensitive matters, follow **[SECURITY.md](SECURITY.md)** instead of opening a public Issue.

## Español

Este repositorio está destinado principalmente a **versiones oficiales de Anti-UAC, documentación pública y soporte a usuarios**. El código fuente de la aplicación no se publica aquí.

Las formas más útiles de colaborar son:

- informar de errores reproducibles mediante Issues;
- proponer mejoras concretas mediante Issues;
- ayudar a otros usuarios en Discussions;
- señalar errores o textos poco claros en la documentación pública.

Las Pull Requests de documentación pueden revisarse, pero no se garantiza que las contribuciones externas sean aceptadas o incorporadas.

Mantén los reportes respetuosos, claros y libres de credenciales, información privada del sistema o ejecutables/archivos que no tengas permiso para compartir.

Para asuntos sensibles relacionados con seguridad, sigue **[SECURITY.md](SECURITY.md)** en lugar de abrir un Issue público.
